# State Transition Diagram
This document outlines the operational flow and logic states of the Star Whale project. 
It follows the lifecycle of a game session from initialization to the final result.

## 1. Whale State Machine
Tracks the lifecycle of an individual vocabulary unit.

| State | Description |
| :--- | :--- |
| **Idle** | Default listener state; serves as the entry point for Studying, Testing, and Result modules. |
| **Studying** | Triggered upon word search; retrieves metadata for display and persists the entry into the study repository. |
| **Testing** | Active game session initiated once the collection threshold (10 words) is met. |
| **Result** | Post-quiz classification into Green (Perfect), Orange (Average), or Red (Review). Supports manual selection for re-collection. |
| **Pending Activation** | An incubation period for Green status words that remain unselected for review. |

## 2. Star State Machine
Manages the gamified collection and progress of word groups.

| State | Description |
| :--- | :--- |
| **Empty** | Initialized state with a null word count (0 words). |
| **Filling** | Incremental aggregation state as words (1–9) are successfully validated and stored. |
| **Twinkling** | Saturation state (10 words); visual indicator that the Quiz Module is executable. |
| **Gold** | Finalized state triggered upon quiz completion; grants authorization to access the Analytics (Report) Module. |
| **Green** | Automated mastery state formed when 10 incubated words complete their 10-day cycle; re-enables Game Module entry. |
